## C) NOT STARTED

### v2.0.0 Git Tag is Stale

The `v2.0.0` tag was created **before** the module path fix. Anyone who runs:

```bash
go get github.com/larsartmann/go-filewatcher/v2@v2.0.0
```

will get a module where the module path is `github.com/larsartmann/go-filewatcher` (no `/v2`) — a mismatch that causes Go tooling confusion.

**Action needed:** Delete and re-tag `v2.0.0`, or release `v2.0.1` with the fix.

### No `govulncheck` or `gosec` in CI

The CI runs `go vet` + `golangci-lint` but not `govulncheck` or `gosec` — recommended by how-to-golang policy.

### No `encoding/json/v2` Adoption

Go 1.25+ provides `encoding/json/v2` (10x faster). The project still uses `encoding/json` v1 in `event.go` for `MarshalJSON`/`UnmarshalJSON`.

`.github/dependabot.yml` exists but hasn't been verified for correct Go module configuration.
